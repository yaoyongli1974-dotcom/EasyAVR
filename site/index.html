能力矩阵

六个能力域，从设备接入到告警处置

01设备接入

  • ONVIF WS-Discovery 主动发现与 IP 网段扫描，勾选后一键导入
  • ONVIF / 海康 ISAPI 自动探测码流，按媒体配置自动建主子码流通道
  • GB28181 接入：REGISTER 摘要鉴权、目录自动建通道、实时 INVITE 点播
  • EHOME / ISUP 私有协议接入端点，默认纯 Go 实现
  • 设备与通道 CSV 批量导入导出

02视频中台

  • ZLMediaKit 内核负责拉流、转码与多协议分发
  • 1 / 4 / 9 / 16 分屏 WebRTC 实时播放，轮播与播放记忆
  • 录像回看：按日期编目检索、0.5–16 倍速回放、按天/时段录像计划
  • 云台 PTZ 方向 / 变倍 / 预置位，按设备协议自动路由
  • 通道诊断：ffprobe 播放诊断 + VQD 十二项视频质量检测

03AI 中台

  • CV / VLM / LLM 多 provider 统一抽象，任何兼容后端实现接口即可接入
  • AI 任务支持 ROI 区域、分析灵敏度与每天 / 工作日分析计划
  • ffmpeg 帧抽取，CV / VLM 不需要经过浏览器
  • 模型注册 / 版本 / 部署三层管理，与运行时能力状态联动
  • 数据集（可从事件快照导入样本）、标注任务与训练作业

04事件中心

  • 告警策略分级分发：即时投递 + 未确认延迟升级
  • 冷却抑制与事件确认，确认后阻止继续升级
  • 投递全量审计；Webhook / 邮件渠道按级别、类型匹配
  • AI 事件地图按通道 GPS 落点，按级别过滤与统计
  • 语义检索：事件向量化 + 余弦检索，未配置嵌入模型时退化为关键词

05国标与合规

  • GB28181 级联：作为下方向上级平台注册，支持白名单
  • GA/T1400（VIID）结构化与告警 XML 入库，上下级级联与订阅
  • GB35114：SM2 平台 CA、设备证书签发 / 登记 / 校验 / 吊销
  • SM3 摘要工具与 GM/T 0024 安全 SIP / TLS 双向证书认证
  • GB28181 / EHOME 注册黑白名单拦截

06开放与运维

  • 开放 API：/api/v1/open/*，API Key + scope + 限流 + 每日配额 + 审计
  • OpenAPI 3.0 文档随服务提供
  • 集群：节点注册 / 心跳，设备按节点负载分配
  • Casbin 统一权限策略，默认 admin / operator / viewer
  • 播放地址 HMAC 签名鉴权，支持来源白名单与 ZLM on_play 钩子校验

架构

三平面解耦，AI 是独立平面

三平面的职责边界

EasyAVR 的三平面分工明确：设备接入平面负责把异构协议归一化为通道；流处理整体交给外置内核 ZLMediaKit，平台自身只做资源编目与业务编排；AI 是与视频平行的独立中台——任何 AI 后端实现统一的 Analyzer 接口即可接入，按任务调度，产出统一结构的事件，分析逻辑不嵌入取流链路。

两个中心把结果收敛：视频资源中心统一编目实时流、录像与快照；AI 事件中心负责事件的存储、语义检索、分级分发与地图呈现。Web、APP 与第三方系统共用同一开放层，不各自造接口。

快速开始

三步跑起来

  1. 1

    启动流媒体内核

    ZLMediaKit 经 docker compose 启动，负责拉流、转码与多协议分发。

    shell
    docker compose up -d
  2. 2

    启动后端 API

    默认监听 :18000，内置 SQLite 零依赖启动；首次启动自动建管理员（easyavr / easyavr）。

    shell
    make deps
make run
  3. 3

    启动前端开发服务器

    默认端口 5173，/api 自动代理到 :18000。生产改为 make web-build，由后端直接托管 web/dist。

    shell
    make web-dev

需要 PostgreSQL 时设置 EASYAVR_DB_DRIVER=postgres 与 EASYAVR_DB_DSN 即可，两者均为纯 Go 驱动。make test 使用假 CV worker，不依赖 ZLMediaKit 与 ffmpeg，可在任意环境执行。

开放 API

第三方系统与 APP 用同一套接口

curl
curl -H "X-API-Key: 你的API密钥" \
  https://app.easyavr.cn/api/v1/open/devices

# 上报 AI 事件（需要写权限 scope；level 取 info / warning / critical）
curl -X POST -H "X-API-Key: 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{"kind":"cv","eventType":"person_intrusion","level":"warning","channelId":1,"summary":"周界越线告警"}' \
  https://app.easyavr.cn/api/v1/open/events

鉴权与配额

  • X-API-Key 请求头鉴权，密钥在平台「开放 API」页签发
  • 每个密钥绑定读 / 写 scope，越权返回 401
  • 限速 + 每日配额，超限明确报错
  • 每次调用写入审计日志，可在后台回查
  • 可用资源：设备、通道、视频资源、AI 事件（含事件上报）
  • OpenAPI 3.0 文档：GET /api/v1/openapi.json
